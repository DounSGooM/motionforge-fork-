# 简体中文 (zh-CN)

## Pacing
每秒 4–5 个汉字（每分钟约 240–300 字）。30 秒约 135 字，60 秒约 270 字。中文不按空格计词，预算按字数算。

## Register
口语化、直接，用"你"。品牌账号如需更正式，可用"您"，但全片统一。

## Numbers as spoken
| 屏幕显示 | 配音稿写法 |
|---|---|
| 2,000 | 两千 |
| 3.5 倍 | 三点五倍 |
| 47% | 百分之四十七 |
| ¥19/月 | 每月十九元 |
| 10w+ | 十万以上 |
| 14:30 | 下午两点半 |
| 2026 年 | 二〇二六年（先试一句，多数引擎能正确读数字年份） |
| v2 | 第二版 |

注意"二"与"两"：量词前用"两"（两个、两千）。英文缩写（API、AI）写成希望读出的样子并先试听。

## Closing lines (call to action)
- 先收藏，用的时候就能找到，记得关注我。
- 转给那个还在手动做这件事的朋友。
- 评论区回复"模板"，我把文件发给你。
- 链接放在简介里了。

## Hook patterns
1. [P] 这条视频里的每一个特效，都是用___做的。
2. [P] 我没打开任何剪辑软件，做出了这条视频。
3. [C] 大多数人设置___时，都漏掉了这个细节。
4. [C] 一个小设置，对结果的影响比你想的大得多。
5. [S] 要是开始之前有人告诉我这件事就好了。
6. [F] 你明明一直在做___，却没有效果？先看这里。
7. [B] 光靠多发视频，账号不会自己涨。
8. [R] 同一个题材的两条视频，一条播放量是另一条的十倍。差别就在这。
9. [R] 只改一句话，看看会发生什么。
10. [N] ___个能替代___的免费工具。
11. [T] ___做___确实很强，但___还是不行。
