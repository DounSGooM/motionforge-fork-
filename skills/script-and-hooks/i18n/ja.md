# 日本語 (ja)

## Pacing
1秒あたり5〜6文字（漢字かな交じり、1分あたり約300〜350文字）。30秒で約165文字、60秒で約330文字。語数ではなく文字数で予算を立てる。

## Register
SNSでは「です・ます」調の親しみやすい話し言葉が基本。くだけた常体を使う場合は全編で統一する。

## Numbers as spoken
| 画面表示 | 読み上げ原稿 |
|---|---|
| 2,000 | 二千 |
| 3.5倍 | 三・五倍（さんてんごばい） |
| 47% | 四十七パーセント |
| 月額¥1,980 | 月額千九百八十円 |
| 1万 | 一万 |
| 14:30 | 午後二時半 |
| 3つ目 | 三つ目 |
| v2 | バージョン2（ツー／に、読みを試聴して決める） |

読みが揺れる語（「方」「行った」など）や英字略語は、読ませたい形（ひらがな・カタカナ）で書く。

## Closing lines (call to action)
- あとで見返せるように保存して、フォローもお願いします。
- まだ手作業でやっている友だちに送ってあげてください。
- コメントに「テンプレ」と書いてくれたらファイルを送ります。
- リンクは概要欄にあります。

## Hook patterns
1. [P] この動画のエフェクトは、全部___で作りました。
2. [P] 編集ソフトを一度も開かずに、この動画を作りました。
3. [C] ___を設定するとき、ほとんどの人がこの一点を見落としています。
4. [C] 小さな設定ひとつで、結果は想像以上に変わります。
5. [S] 始める前に、誰かにこれを教えてほしかった。
6. [F] ___をやっているのに結果が出ないなら、まずここを見てください。
7. [B] 投稿を増やすだけでは、アカウントは伸びません。
8. [R] 同じテーマの動画二本、片方は再生数が十倍。違いはここです。
9. [R] 一文を変えるだけで何が起きるか、見てください。
10. [N] ___の代わりになる無料ツールを___個紹介します。
11. [T] ___は___がとても得意です。でも___はまだ弱い。
