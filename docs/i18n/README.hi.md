# motionforge

**मोशन डिज़ाइन वीडियो, जिन्हें आपका कोडिंग एजेंट कोड में लिखता है।**

वीडियो के बारे में बताइए। आपका एजेंट हुक और स्क्रिप्ट लिखता है, हर शब्द को वॉइस-ओवर के साथ टाइम करता है, सीन बनाता है, रेंडर करता है, और आपको दिखाने से पहले अपने काम की ख़ुद जाँच करता है।

## यह क्या करता है

आप कुछ ऐसा लिखते हैं:

> उन 5 मुफ़्त टूल्स पर 60 सेकंड की वर्टिकल रील बनाओ जिन्हें मैं रोज़ इस्तेमाल करता हूँ। डार्क स्टाइल, मेरी आवाज़, कैप्शन के साथ।

motionforge इसे तय चरणों से गुज़ारकर एक जाँचा हुआ MP4 बना देता है:

| चरण | क्या होता है |
|---|---|
| **ब्रीफ़** | एजेंट आपके अनुरोध को एक वाक्य में दोहराता है और सिर्फ़ वही पूछता है जो छूट गया है (फ़ॉर्मैट, लंबाई, भाषा, आवाज़)। |
| **हुक और स्क्रिप्ट** | 2–3 हुक विकल्प, बोलने की रफ़्तार के हिसाब से लिखी स्क्रिप्ट, और उन तथ्यात्मक दावों की सूची जिन्हें आपको जाँच लेना चाहिए। कोई मनगढ़ंत आँकड़ा नहीं। कोई घिसे-पिटे "AI वाले वाक्य" नहीं (10 भाषाओं में प्रतिबंधित वाक्यांशों की सूचियाँ)। |
| **आवाज़** | अपनी TTS कुंजी (ElevenLabs, OpenAI) इस्तेमाल कीजिए या कोई लोकल मॉडल चलाइए। किसी भी पेड कॉल से पहले एजेंट लागत बताता है और आपकी "हाँ" का इंतज़ार करता है। |
| **टाइमिंग** | वॉइस-ओवर से हर शब्द का टाइमस्टैम्प लिया जाता है, ताकि हर टाइटल, लोगो और कैप्शन ठीक उसी पल आए जब वह शब्द बोला जा रहा हो। |
| **स्टाइल और ब्रांड** | स्टाइल लाइब्रेरी से कोई लुक चुनिए और अपनी `brand.json` लागू कीजिए (रंग, फ़ॉन्ट, लोगो, वॉटरमार्क, आउट्रो)। |
| **सीन** | ऐसे डिटरमिनिस्टिक कोड के रूप में बनाए जाते हैं जिसमें किसी भी पल पर सीधे जाया जा सके: डिफ़ॉल्ट रूप से HyperFrames (HTML + GSAP), और जहाँ बेहतर बैठें वहाँ Remotion या canvas इंजन। |
| **QA** | कॉन्टैक्ट शीट, टेक्स्ट ओवरफ़्लो और सेफ़ एरिया की जाँच, स्क्रीन पर पढ़ने का समय, लाउडनेस, और नए कॉन्टेक्स्ट वाला एक समीक्षक जिसने सीन ख़ुद नहीं लिखे। |
| **डिलीवरी** | 9:16 / 1:1 / 16:9 में MP4, एक कवर इमेज, कैप्शन और पोस्ट का विवरण। बदलाव टाइमस्टैम्प से बताइए: "0:12 वाला टाइटल बदल दो"। |

## इंस्टॉल

### Claude Code (प्लगइन)

```text
/plugin marketplace add aykutucesai/motionforge
/plugin install motionforge@motionforge
```

इसके बाद बस एक वीडियो माँगिए। `motion-director` स्किल काम सँभाल लेती है।

### Codex, Cursor और दूसरे एजेंट

```bash
git clone https://github.com/aykutucesai/motionforge
```

फ़ोल्डर खोलिए (या उसे अपने प्रोजेक्ट में जोड़िए) और एजेंट को [`AGENTS.md`](../../AGENTS.md) फ़ॉलो करने को कहिए। हर स्किल सटीक कमांड्स वाली सादी Markdown फ़ाइल है, इसलिए जो भी एजेंट फ़ाइलें पढ़ सकता है और शेल चला सकता है, वह इसे फ़ॉलो कर सकता है।

### ज़रूरतें

- Node.js 18+ (22 बेहतर है) और ffmpeg
- Python 3.10+
- वैकल्पिक: `faster-whisper` (शब्द-टाइमिंग), `rembg` (बोलते हुए व्यक्ति का कट-आउट), `fonttools` (ग्लिफ़ जाँच), Playwright Chromium

एजेंट हर काम की शुरुआत में इन्हें जाँचता है और साफ़-साफ़ बताता है कि क्या इंस्टॉल करना है।

## ये प्रॉम्प्ट आज़माइए

```text
इस वॉइस-ओवर (voice.mp3) को 9:16 रील में बदलो। काइनेटिक कैप्शन, डार्क स्टाइल, और मैं जिस भी प्रोडक्ट का नाम लूँ उसका असली लोगो।
```
```text
इन 4 स्क्रीनशॉट से मेरे ऐप के लिए 30 सेकंड का प्रोडक्ट लॉन्च क्लिप बनाओ। मेरा ब्रांड किट इस्तेमाल करो।
```
```text
सॉफ़्टवेयर पर पैसे बचाने के बारे में स्पैनिश में 3 हुक विकल्प और 70 सेकंड की स्क्रिप्ट लिखो। अभी ऑडियो मत बनाना।
```
```text
ये अपनी डेस्क पर बैठे हुए मेरी 10 सेकंड की क्लिप है। पहले 5 सेकंड इंट्रो में और आख़िरी 5 सेकंड आउट्रो में इस्तेमाल करो, बीच में ग्राफ़िक्स रखो।
```

## अंदर क्या है

```
motionforge/
├─ AGENTS.md                 किसी भी एजेंट के लिए शुरुआती बिंदु
├─ skills/
│  ├─ motion-director/       पूरा वर्कफ़्लो और उसके अप्रूवल पड़ाव
│  ├─ script-and-hooks/      हुक, स्क्रिप्ट, दावों की सूची, प्रतिबंधित वाक्यांश (10 भाषाएँ)
│  ├─ voice-and-timing/      सहमति के बाद ही TTS, शब्द-टाइमिंग, कैप्शन, लाउडनेस
│  ├─ style-library/         20 लुक, हर एक की अपनी STYLE.md
│  ├─ brand-kit/             brand.json: रंग, फ़ॉन्ट, लोगो, वॉटरमार्क, आउट्रो
│  └─ qa-review/             जाँचें + स्वतंत्र समीक्षक
├─ engines/
│  ├─ hyperframes/           डिफ़ॉल्ट इंजन (HTML + GSAP, Apache-2.0)
│  ├─ remotion/              वैकल्पिक React इंजन + किट
│  └─ canvas/                हाथ से बने और प्रोसीजरल लुक के लिए frame = f(t) पेज
├─ templates/                तैयार सीन: काइनेटिक टाइटल, कैप्शन, काउंटर, ब्राउज़र, फ़ोन, चैट, चेकलिस्ट, कवर
└─ tools/                    शब्द-टाइमिंग, कट-आउट, लाउडनेस, कॉन्टैक्ट शीट, टेक्स्ट जाँच, एक्सपोर्ट, कवर का सेफ़ एरिया
```

## सिद्धांत

1. **डिफ़ॉल्ट रूप से सबके लिए मुफ़्त।** डिफ़ॉल्ट इंजन HyperFrames का लाइसेंस Apache-2.0 है। Remotion वैकल्पिक है ([लाइसेंसिंग](../LICENSING.md) देखें)।
2. **डिटरमिनिस्टिक।** हर फ़्रेम समय का फ़ंक्शन है। इनपुट वही, तो वीडियो भी वही।
3. **सहमति के बिना कोई पेड काम नहीं।** एजेंट पहले लागत बताता है।
4. **ईमानदार कंटेंट।** जिन दावों के लिए स्रोत चाहिए, उनकी सूची आपको दी जाती है; मॉक स्क्रीन को साफ़ तौर पर मॉक बताया जाता है।
5. **डिलीवरी से पहले जाँच।** अगर QA में कोई विफलता अब भी खुली है, तो वीडियो डिलीवर नहीं होता।
